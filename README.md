# Project Miami

*Formerly Neon Death Grade.*

A personal Project Zomboid Build 42 mod inspired by arcade-style scoring systems and Hotline Miami.

The mod adds a combo system, a custom death screen with scoring categories and grades, a weapon HUD, a dynamic soundtrack and a restyled main menu.

Available on the Steam Workshop: [Project Miami [B42]](https://steamcommunity.com/sharedfiles/filedetails/?id=3842895126)

## Features

- Combo counter: kills within 6 seconds of each other build a chain
- Point popups above every killed zombie, combo bonus included
- Animated death screen with seven scoring categories (Kills, Combo, Flexibility, Mobility, Boldness, Time Bonus, Special) and a grade from F to S
- Death screen can be skipped and closed with the mouse, keyboard or a controller
- Weapon HUD with loaded rounds, reserve ammo and a chambered round indicator
- Dynamic soundtrack: calm and combat playlists, a horde track, themes for map landmarks, wake-up and loading music
- Animated Hotline Miami 2-style main menu

## Installation

Subscribe on the Steam Workshop to get the full mod. Build 42 only.

This repository contains the code and art but not the soundtrack: the music files belong to their artists and are not stored here. Without them the mod still runs, only the music is silent.
